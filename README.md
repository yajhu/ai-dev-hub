# AI Dev Hub

SpringBoot + Java 8 + Maven project with MyBatis-Plus and PostgreSQL.

## Tech Stack

- Java 8
- SpringBoot 2.7.18
- MyBatis-Plus 3.5.5
- PostgreSQL 42.7.1
- Lombok

## Quick Start

```bash
mvn spring-boot:run
```

## Project Structure

```
src/main/java/com/aidevhub/
├── AiDevHubApplication.java
├── controller/
├── service/
│   └── impl/
├── mapper/
├── model/
└── config/
```
